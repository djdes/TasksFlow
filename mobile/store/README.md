## Тексты

**Подзаголовок (App Store, 30):** Чек-листы и фотоотчёты

**Краткое описание (Google Play, RuStore, 80):**
Задачи смены, чек-листы и фотоотчёты: отметил с фото — руководитель видит

**Рекламный текст (App Store, 170):**
Сотрудник видит задачи смены и отмечает их с фото — руководитель сразу видит
результат. Напоминания, премии и журнал дня в одном приложении.

**Ключевые слова (App Store, 100):**
`задачи,чек-лист,фотоотчет,смена,сотрудники,контроль,премия,кафе,магазин,уборка,журнал,персонал,фото`

**Полное описание:**

> TasksFlow — задачи на смену для кафе, магазинов, клининга и любых команд,
> где работа делается руками и важно видеть результат.
>
> Сотруднику
> • Задачи на сегодня — сразу при входе, по порядку и с чек-листами.
> • Фотоотчёт с камеры в одно касание: время и название компании на снимке,
>   фото сжимается и уходит за секунды.
> • Нет связи — фото встаёт в очередь и отправится само.
> • Уведомления о новых задачах, возвратах на доработку и напоминания
>   утром и вечером.
> • Премии за выполненное видны в приложении.
>
> Руководителю
> • Сводка смены: сколько сделано, кто отстаёт, что не начато.
> • Проверка работы: фото рядом с эталоном, принять или вернуть с причиной.
> • Журнал дня и отчёты по людям за неделю или месяц, выгрузка в Excel.
> • Повторяющиеся задачи по дням недели, шаблоны для своей отрасли,
>   несколько точек.
>
> Вход — по номеру телефона и PIN. Кабинет компании создаётся на
> tasksflow.ru за минуту; посмотреть без регистрации — кнопка «Демо» на
> экране входа.

## Ответы для ревью App Store

- **Вход:** номер телефона и PIN из 4 цифр. Без аккаунта — кнопка «Демо» на
  экране входа: кабинет кофейни с задачами, фотоотчётами и отчётами, данные
  только на устройстве.
- **Тестовый аккаунт для ревьюера:** заведите отдельную компанию на
  tasksflow.ru (например, «App Review»), добавьте сотрудника с PIN и впишите
  телефон и PIN в App Store Connect → App Review Information.
- **Зачем камера и фото:** фотоотчёт о выполненной задаче (снимок прикрепляется
  к задаче и виден руководителю).
- **Push:** новые задачи, возвраты на доработку, напоминания по расписанию
  компании.
- **Шифрование:** только HTTPS — `ITSAppUsesNonExemptEncryption = NO`.

## Конфиденциальность (App Privacy / «Безопасность данных»)

Сбор — для работы приложения, не для рекламы и не для отслеживания. Данные
передаются только по HTTPS; аккаунт удаляется в «Аккаунт → Опасная зона».

| Данные | Зачем | Связаны с человеком |
|---|---|---|
| Имя, телефон, email | аккаунт, вход | да |
| Фото | фотоотчёты по задачам | да |
| Действия в приложении (выполненные задачи) | работа приложения, отчёты руководителю | да |
| Идентификатор устройства для push | уведомления | да |
| Диагностика (ошибки приложения) | исправление ошибок | нет |

Отслеживания (ATT) нет, сторонней рекламы и аналитики в приложении нет.
